# IMP-II-Automne-2026

Chaque membre de l’équipe devra créer sa propre branche dans le dépôt GitHub pour développer ses fonctionnalités ou corriger des bugs. Chacun pourra y faire ses commits, pousser son travail et ouvrir une Pull Request (PR) lorsqu’il souhaite intégrer ses modifications. Cela permet de travailler en parallèle sans toucher directement à la branche principale, ce qui évite les conflits et garde le projet stable.

De mon côté, je jouerai le rôle de responsable de l’intégration : je vérifierai chaque Pull Request, commenterai si nécessaire, demanderai des ajustements et approuverai les modifications lorsqu’elles sont prêtes. Une fois validées, je fusionnerai les branches dans main, ce qui garantit que seules les contributions testées et approuvées entrent dans la version officielle du projet.
